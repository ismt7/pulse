# Pulse

小さな前進が、楽しみになる。Pulseは、KPIや個人目標の進み具合を記録し、グラフや達成率で振り返れるダッシュボードです。

## 主な機能

- 目標名、目標値、単位、テーマカラーの設定
- 数値を増やす目標と減らす目標
- 累計値・現在値、または日ごとの増分による記録
- 期間なし、月次、四半期、任意期間の目標
- 達成率、推移グラフ、履歴、直近の平均達成率
- 記録の修正・削除、次の期間への目標複製
- 目標の検索・並び替え
- JSONバックアップ・復元、CSV書き出し
- スマートフォン表示とキーボード操作

## 使い始める

Pulseはローカル環境で動作します。Node.js 24とnpmを用意し、次のコマンドを実行してください。

```sh
npm ci
npm run dev
```

ターミナルに表示されたアドレスをブラウザで開きます。初回はサンプルデータが表示されるため、操作を試してから「自分の目標ではじめる」で削除できます。

Dockerを利用する場合は `docker compose up --build` で起動できます。詳しい開発手順は [DEVELOPMENT.md](DEVELOPMENT.md) を参照してください。

公開されたWindows、macOS、Linux向けデスクトップ版は [GitHub Releases](https://github.com/ismt7/pulse/releases) からダウンロードできます。リリース準備と対応ファイルについては [DESKTOP.md](DESKTOP.md) を参照してください。

## 目標と実績を記録する

目標の作成時に「数値を増やす」または「数値を減らす」を選びます。増やす目標では、現在の合計を入力する「累計値・現在値」と、日々の値を足し上げる「日ごとの増分」を選べます。減らす目標では開始値を設定し、開始値から目標値までの減少量で達成率を計算します。

同じ日付にもう一度入力すると、その日の記録を上書きします。実績がある目標では、計算結果を保つため目標の方向と記録方式を変更できません。

## 期間を設定する

目標期間は「期間なし」「月次」「四半期」「任意」から選べます。期間内の記録だけが集計され、期間終了後も最終達成率を確認できます。

詳細画面の「次の期間へ複製」を使うと、月次・四半期は次の暦期間へ、任意期間は同じ日数の直後の期間へ目標を複製できます。記録は複製されません。

## 履歴を確認・修正する

各カードの「履歴と詳細を見る」から、実績、達成率、推移グラフ、すべての記録を確認できます。累計値方式では、過去の値を修正しても後日の値は変わりません。増分方式では、修正・削除した日以降の累計が自動で再計算されます。

## データをバックアップする

データは利用中のブラウザ内に保存され、サーバーへ送信されません。アカウント登録やオンライン同期もありません。ブラウザデータを削除すると記録が失われるため、定期的にJSONを書き出してください。

復元する場合は、画面下部の「データを読み込む」からPulseで書き出したJSONを選択します。復元すると現在の目標と記録がすべて置き換わります。CSVは表計算ソフトで集計したい場合に利用できます。
