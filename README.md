# Pulse

小さな前進が、楽しみになる。KPI や個人目標の実績を記録する、ローカル向けダッシュボードです。

## 開発

React + TypeScript + Vite で構築しています。スタイルは CSS、グラフは Recharts、テストは Vitest + Playwright を使用しています。

Node.js 24 と npm を推奨します。対応する Node.js の範囲は `package.json` の `engines` に記載しています。

```sh
npm ci
npm run dev
```

ターミナルに表示されたアドレスをブラウザで開いてください。Vite はクラウド開発用に全インターフェースで待ち受けます。自分の端末だけで使う場合は `npm run dev -- --host 127.0.0.1` で起動できます。サイトへのデプロイ設定は含みません。

## できること

- 目標名・目標値・単位・テーマカラーの登録、編集、削除
- 日付ごとの累計実績の記録（同じ日付は上書き）
- 指標ごとの詳細表示、全記録のグラフと履歴、過去の累計値の修正・記録の削除
- 指標ごとの記録方式（累計値・現在値／日ごとの増分）
- 開始値から目標値までの進捗を測る「数値を減らす」目標
- 期間なし・月次・四半期の目標期間
- 任意の開始日・終了日、次期間への目標複製
- 目標の検索・並び替え、集計用CSV書き出し
- 達成率、直近 7 日・30 日の平均達成率、最近の記録の表示
- 目標達成時のお祝い（動きを減らす設定にも対応）
- ブラウザ内の保存、JSON 書き出し・バックアップからの復元
- スマートフォン表示、キーボード操作

初回はサンプルデータを表示します。「自分の目標ではじめる」でサンプルを削除できます。目標の作成時に「数値を増やす」または「数値を減らす」を選びます。減らす目標では目標値より大きい開始値を設定し、開始値から目標値までの減少量で達成率を計算します。

増やす目標では「累計値・現在値」または「日ごとの増分」を選べます。累計値では最新の日付の記録を現在値にし、増分では全日の入力を自動で合計します。減らす目標は現在値を記録します。同じ日付への入力はいずれも上書きです。既存データは「数値を増やす・累計値」として引き継ぎます。数値の意味を守るため、実績がある目標の方向・記録方式は変更できません。期間ごとの自動リセットには未対応です。

目標期間は「期間なし」「月次」「四半期」「任意」から選べます。月次は選択月、四半期は選択月を含む暦年の四半期を対象にします。期間内の記録だけを集計し、期間終了後も最終達成率を表示します。将来の期間には記録できません。記録後は期間を変更できません。既存データは期間なしとして引き継ぎます。

任意期間では開始日と終了日を直接指定できます。詳細画面の「次の期間へ複製」は、月次・四半期を次の暦期間へ、任意期間を同じ日数の直後の期間へ複製します。期間なしの目標は「コピー」として複製します。記録は複製されません。

ダッシュボードでは目標名で検索し、名前・達成率・最近の記録で並び替えられます。JSONはバックアップと復元用、CSVは表計算ソフトでの集計用です。CSVには各入力値と、その日時点の累計・現在値を出力します。

データは利用中のブラウザの `localStorage` に保存されます。サーバーへの送信、アカウント、同期、解析用通信はありません。ブラウザデータの削除や利用するオリジンの変更でデータが失われる・見えなくなる場合があります。必要に応じて JSON を書き出してください。

### 履歴の確認・修正

各カードの「履歴と詳細を見る」で、現在の実績・目標・達成率と、全記録のグラフ・履歴を確認できます。履歴は新しい日付順に10件ずつ表示します。累計値方式の古い記録を修正しても後日の値は変わりません。増分方式では、その日の入力の修正・削除に合わせて以降の累計を再計算します。記録がなくなると現在値は0になります。

### バックアップの復元

画面下部の「データを読み込む」から、Pulse で書き出した JSON（10 MB以下）を選択します。目標数・記録数・先頭5個の目標名を確認し、置き換え確認にチェックして「この内容で復元」を押してください。復元は追加・統合ではなく、現在の目標と記録をすべて置き換えます。必要なデータは事前に書き出してください。目標が0個のバックアップも復元できます。

バージョン1の保存形式に対応します。不正な目標値・日付、重複した目標ID・同一目標の同日記録などを含むファイルは拒否します。キャンセル、不正なファイル、保存失敗の場合は現在のデータを変更しません。ファイルはブラウザ内で処理され、外部へ送信されません。

## 検証

```sh
npm test
npm run typecheck
npm run build
npx playwright install chromium
npm run test:e2e
```

既存の Chromium を使う場合は `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e` を指定できます。E2E テストは開発サーバーを自動で起動し、サンプル削除、目標作成・編集、記録、再読み込み後の保存、絞り込み、削除、モバイル表示を検証します。

`npm test` は Vitest を一度実行します。開発中の監視実行には `npm run test:watch` を使います。`npm run build` は TypeScript の型チェックも実行します。GitHub Actions の CI でも単体テスト・型チェック付きビルド・E2E テストを実行します。

## コード構成

```text
src/
  App.tsx              画面の構成と操作の接続
  components/          目標カード、フォーム、グラフ、共通のダイアログなど
  hooks/useDashboard.ts  保存データと React の状態を接続
  types.ts             目標・実績・保存形式の型
  model.ts             達成率の計算、入力検証、累計記録の更新
  storage.ts           保存データの読み書き
test/                  Vitest の計算・保存互換性テスト
e2e/                   Playwright のブラウザ操作テスト
```

初期版の保存キー `pulse.dashboard.v1` とデータ形式を維持しているため、同じブラウザ・オリジンであれば移行前の記録を引き継ぎます。保存失敗時は画面の実績を更新せず、入力内容をフォームに残します。期間ごとの目標は今後の拡張です。
